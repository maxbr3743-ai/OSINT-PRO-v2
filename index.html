Segurança e uso responsável

Limites e recomendações para o uso do painel.

Fontes públicas

Use páginas abertas, documentação pública, notícias e registros que possam ser consultados legitimamente.

Verificação

Um nome, uma foto ou um resultado isolado não prova identidade. Confirme informações antes de tirar conclusões.

Privacidade

Não tente contornar logins, CAPTCHA ou controles de acesso. Evite perseguição, assédio e divulgação indevida.

Limitação técnica

Este é um painel estático. As notas e o histórico ficam no navegador atual. Para contas reais, administração segura, pagamentos, API privada e banco de dados compartilhado, é necessário desenvolver um backend.
